## Supported Versions
Only the latest release on the `main` branch receives active security updates and vulnerability patches.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability
We take the validation of our secure repository deployment keys and identity architectures very seriously. 

**Do not open public GitHub issues for security vulnerabilities.**

If you discover a security leak, configuration bypass, or cryptographic flaw within the deterministic sequential logic gates:
1. Email a detailed report directly to the security anchor mailbox: **myou260312@gmail.com** or **harigov63@gmail.com**.
2. If encryption is required, request our GPG public key by contacting the emails listed above.
3. A response will be coordinated within 48 hours to execute a localized mitigation update.

Thank you for helping keep sovereign AI infrastructure clean, tamper-proof, and secure.
